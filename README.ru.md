Typr — лёгкое приложение для голосового ввода на Windows. Нажимаешь глобальный хоткей, говоришь, и распознанный текст вставляется в активное окно. А ещё оно умеет отвечать: спросите ИИ о выделенном тексте или поговорите с ним голосом в маленьком окне у края экрана.

## Возможности

### Диктовка

- **Глобальный хоткей** в двух режимах (переключение или удержание): сочетание клавиш или одна кнопка мыши (средняя или боковая). Оба хоткея, для диктовки и для Quick Chat, настраиваются в разделе «Хоткеи».
- **Индикатор записи:** маленький микрофон появляется только во время диктовки (запись, распознавание, вставка) и снова прячется. Он выезжает из-за верхнего края экрана в правом верхнем углу или из-за панели задач внизу по центру, как выберете.
- **Чистый буфер обмена:** продиктованный текст вставляется через буфер, не попадает в журнал буфера Windows.
- **Пробел после текста**, чтобы следующая фраза не слипалась с предыдущей.

### Распознавание речи

- **Локальное распознавание** через [transcribe.cpp](https://github.com/handy-computer/transcribe.cpp): Parakeet TDT 0.6B v3, Whisper Large v3, Large v3 Turbo и Medium работают прямо на компьютере, звук никуда не уходит. Работают на видеокарте через Vulkan (NVIDIA, AMD или Intel) или на процессоре. Модели скачиваются и удаляются в настройках, неиспользуемая модель сама выгружается из памяти.
- **Облачные провайдеры распознавания:** Groq (Whisper Large v3/v3 Turbo), [Polza.AI](https://polza.ai/), [AssemblyAI](https://www.assemblyai.com/) (Universal-3.5 Pro/Universal-2), а также любой OpenAI-совместимый эндпоинт. Запись уходит в FLAC, где сервис его принимает, по соединению, открытому, пока вы говорите.
- **Запасной локальный движок:** если облако не справилось, диктовку распознает скачанная локальная модель; следующая снова пойдёт в облако.
- **Язык речи:** определяется автоматически или задаётся (русский, английский и другие) — так точнее распознаются короткие фразы.

### Текст

- **Постобработка:** нейросеть (Gemini, OpenRouter, Groq или Polza) дорабатывает текст перед вставкой в одном из стилей: «Чилл», «Грамотный» или свой.

### ИИ-помощник

Quick Ask и Quick Chat — названия функций, поэтому и в русском интерфейсе они не переводятся.

- **Quick Ask:** выделите текст в любом приложении, нажмите хоткей диктовки и спросите о нём вслух («переведи это», «что значит эта ошибка»). Индикатор записи разворачивается в маленькое окно с ответом, а фокус остаётся в приложении, где вы были; нажмите хоткей ещё раз, чтобы задать уточняющий вопрос в том же разговоре. По умолчанию выключено.
- **Quick Chat:** отдельный хоткей (по умолчанию Ctrl+Alt) открывает то же окно как чат с ИИ, выделять ничего не нужно. Спрашиваете вслух хоткеем диктовки: ваши вопросы появляются справа, ответы под ними, а текст, выделенный перед вопросом, уходит вместе с ним. Тот же хоткей или крестик закрывает чат. Хоткеем могут быть два модификатора (срабатывают, когда их отпускаете, поэтому Ctrl+Alt+Delete и другие сочетания его не вызывают), сочетание клавиш или кнопка мыши. По умолчанию выключено.
- **Поиск в интернете:** с ключом [Exa](https://exa.ai/) модель ищет в сети, когда вопросу нужны свежие факты (в это время мигает «Поиск…»), и называет источники ссылками, которые открываются в браузере.
- **Удобные ответы:** форматированный текст, списки и код; клик по ответу копирует его. Отвечает Gemini, OpenRouter, Groq или Polza, модель выбираете вы.

### Приложение

- **API-ключи в одном месте:** ключ каждого сервиса вводится один раз в разделе «API-ключи», в остальных разделах выбираются только сервис и модель. Ключи из прошлых версий переезжают туда сами.
- **Мастер настройки** при первом запуске: язык интерфейса, способ распознавания (с рекомендацией для этого компьютера), модель или ключ, хоткей.
- **Меню в трее:** вставить последнюю диктовку ещё раз, сменить движок, открыть настройки, выключить хоткеи (например, на время игры).
- **Запуск вместе с Windows** (по желанию) и **проверка новых версий на GitHub.**
- **Минимум памяти:** около 5 МБ ОЗУ в трее! WebView окна настроек выгружается после закрытия, а индикатор записи рисуется нативно.
- **Режим разработчика:** живой лог всего, что делает приложение, для поиска проблем. Там же можно держать WebView2 фоном: Quick Ask, Quick Chat и окно настроек открываются быстрее, но в простое занято больше ОЗУ (около 140 МБ сверху).
- **Интерфейс на русском и английском**, тёмный и минималистичный, в стиле Anthropic, со своими кнопками окна вместо системного заголовка.

## Сборка

Установщик собирает GitHub Actions (`.github/workflows/build.yml`) при пуше тега вида `v*` или при ручном запуске workflow:

```bash
git tag v3.0.1
git push origin v3.0.1
```

Для локальной разработки нужны [Rust](https://rustup.rs/) и [Node.js](https://nodejs.org/) 20+:

```bash
npm install
npm run tauri dev
```

Сделано на [Tauri 2](https://tauri.app/) (Rust) и чистом TypeScript.
